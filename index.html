왜 원본 인증인가

진짜로 찍은 사진이라는 걸 보여 줘야 할 때가 있습니다

사진 한 장을 몇 초 만에 합성하고 고칠 수 있는 시대입니다. “보정 없이 찍었어요”라는 말만으로는 부족한 순간이 생깁니다. 최박사사진관은 발급하는 원본 파일마다 지문을 남겨, 필요할 때 원본 파일과 같은지 누구나 확인할 수 있게 합니다.

증명·취업 사진

제출한 파일이 스튜디오가 발급한 원본 파일 그대로인지, 발급 이후 바뀌지 않았는지 확인할 수 있습니다.

프로필·SNS

보정 전 원본 파일을 그대로 건네면, 받는 사람이 스튜디오가 발급한 원본과 같은 파일인지 직접 확인할 수 있습니다. 보낸 사람의 신원까지 확인해 주지는 않습니다.

소상공인 제품 실사

실물을 그대로 찍은 원본 파일을 인증서와 함께 보관해 두세요. 필요할 때 상세 페이지 사진과 나란히 꺼내 보여 줄 수 있습니다.

가족 기록

돌·만삭·가족사진을 찍은 그날의 원본 그대로 남겨 두세요. 발급 일시와 지문이 함께 기록됩니다.

촬영부터 확인까지

이렇게 진행됩니다

  1. 셀프 촬영

    스튜디오 카메라 앞에서 리모컨으로 직접 셔터를 누르세요. 큰 라이브뷰 모니터로 표정과 포즈를 보면서 찍습니다.

  2. 컷 셀렉

    셀렉 스테이션에서 찍은 컷을 살펴보고 받아 갈 사진을 고르세요.

  3. 원본 인증서 발급

    고른 원본 파일마다 지문(SHA-256)을 계산해 인증서 번호·발급 일시와 함께 원본 인증서를 발급합니다. 지문은 파일 내용으로 계산한 64자리 값으로, 파일이 조금만 달라져도 전혀 다른 값이 나옵니다. 모든 촬영에 기본 포함입니다.

  4. NFT 원본 등록 (선택)

    원하는 컷만, 별도 동의를 받은 뒤 지문·인증서 번호·발급 일시를 공개 블록체인에 기록합니다. 사진·얼굴·개인정보는 올리지 않습니다. 블록체인 기록은 지울 수 없어서 지문만 남깁니다. 지갑 없이 스튜디오가 기록합니다. 가상자산이 아닌 확인용 기록으로 투자·거래·결제 수단이 아니며, 가격이나 이익을 약속하지 않고 재판매 시장도 운영하지 않습니다.

  5. 누구나 확인

    원본 확인 페이지에서 파일을 고르면 브라우저 안에서 지문을 계산해 공개 레지스트리와 비교합니다. 사진 파일은 브라우저 밖으로 전송되지 않습니다.

셀프로 찍은 사진의 권리는 고객께 있습니다. 스튜디오는 동의 없이 고객 사진을 홍보에 쓰지 않습니다.

원본 인증서 미리보기

사진마다 한 장, 원본 인증서

인증서에는 원본 파일의 지문(SHA-256), 인증서 번호, 발급 일시, 파일 크기·해상도·형식이 담깁니다. 같은 내용이 공개 레지스트리(certificates.json)에도 기록되어 누구나 대조할 수 있습니다. 이름·연락처·사진은 인증서와 레지스트리 어디에도 넣지 않습니다.

원본 사진 파일은 고객께 전달하고, 스튜디오 보관본은 전달 후 30일이 지나면 삭제할 예정입니다. 보관 기간은 오픈 때 확정해 안내합니다.

인증서가 확인해 주는 것은 “이 파일이 그 시각 스튜디오가 발급한 원본 파일과 같다”는 사실입니다. 사진에 담긴 내용의 사실 여부나 누군가의 신원을 증명하지 않으며, 법적 증거 효력을 보장하지 않습니다.

원본 인증, 이것이 궁금합니다

보정한 사진도 인증되나요?

아니요. 원본 인증서는 스튜디오가 발급한 원본 파일에만 해당합니다. 보정, 자르기, 필터, 형식 변환처럼 파일을 조금이라도 바꾸면 지문이 완전히 달라져 원본과 일치하지 않는 것으로 나옵니다. 보정본을 쓰시더라도 원본 파일은 따로 보관해 두세요.

눈으로는 거의 같아 보이는 밝기 4% 보정본으로 직접 확인해 볼 수 있습니다.

카톡으로 보내도 원본 확인이 되나요?

카카오톡 같은 메신저로 사진을 보내면 대부분 재압축되어 파일이 바뀝니다. 그러면 지문도 달라져 원본 확인이 되지 않습니다. 스크린샷도 마찬가지입니다.

확인이 필요할 때는 메일 첨부나 파일 전송처럼 파일을 그대로 전달하는 방법으로 원본 파일을 보내 주세요. 받는 사람은 원본 확인 페이지에서 바로 확인할 수 있습니다.

NFT는 코인인가요?

아니요. NFT 원본 등록은 사진 파일의 지문을 공개 블록체인에 남기는 확인용 기록입니다. 가상자산이 아니며 투자·거래·결제 수단이 아닙니다. 어떤 가격이나 이익도 약속하지 않고, 스튜디오는 재판매 시장을 운영하지 않습니다.

등록은 선택이며, 컷당 3,000원(오픈 예정가 · 확정 전)은 기록 작업에 대한 요금입니다. 지갑 없이 스튜디오가 기록하고, 확인은 인증서 링크로 하시면 됩니다. 기록할 블록체인 네트워크는 오픈 때 안내합니다.

제 얼굴이 블록체인에 올라가나요?

아니요. 블록체인에는 사진 파일의 지문(SHA-256), 인증서 번호, 발급 일시만 기록합니다. 사진, 얼굴, 이름·연락처 같은 개인정보는 올리지 않습니다.

블록체인 기록은 한 번 남기면 지울 수 없습니다. 그래서 지문만 기록합니다. NFT 원본 등록은 선택이며, 별도로 동의하신 경우에만 진행합니다.
