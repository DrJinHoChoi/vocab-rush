VOCAB RUSH 소개

직장인과 학생을 위한 타이머 기반 학습 챌린지 게임

VOCAB RUSH란?

VOCAB RUSH는 영어 어휘, 수학, 한국어 학습을 게임 형식으로 즐길 수 있는 무료 웹 애플리케이션입니다. 제한 시간 안에 문제를 풀면서 자연스럽게 실력을 향상시킬 수 있습니다.

회원가입 없이 브라우저에서 바로 시작할 수 있으며, PWA(Progressive Web App)를 지원하여 스마트폰 홈 화면에 앱처럼 설치할 수도 있습니다.

학습 모드

📖 영어 어휘 (Vocabulary)

5,000개 이상의 영어 단어를 수준별로 학습합니다.

  • CEFR 기준 A1(기초) ~ C2(최상급) 난이도 분류
  • SAT/GRE 수준의 고급 어휘 포함
  • IT/테크 분야 전문 용어
  • 영어 발음 듣기 + 한국어 뜻 보기 + 4지선다 퀴즈
  • 예문과 힌트 기능으로 문맥 속 학습 가능

🔢 수학 (Math)

다양한 수학 분야의 문제를 풀어보세요.

  • 사칙연산, 분수, 방정식, 기하학 등
  • 프로그래밍 관련 수학(진법 변환, 비트 연산 등)
  • 실생활 응용 문제

🇰🇷 한국어 (Korean)

한국어 어휘력과 문법 실력을 테스트합니다.

  • 맞춤법, 사자성어, 속담
  • IT/비즈니스 용어
  • 올바른 표현 찾기

주요 기능

  • 3단계 난이도 - Easy(15초) / Medium(10초) / Hard(6초)
  • 콤보 시스템 - 3연속 정답 시 보너스 점수
  • 통계 추적 - 누적 정답 수, 최고 점수, 연속 정답 기록
  • 뱃지 시스템 - 다양한 도전 과제 달성
  • 음성 지원 - 영어 단어 발음 듣기 (Web Speech API)
  • 오프라인 지원 - PWA로 인터넷 없이도 플레이 가능

이런 분들에게 추천합니다

  • 출퇴근 시간에 짧게 영어 단어를 외우고 싶은 직장인
  • TOEIC, TOEFL, 수능 영어를 준비하는 학생
  • IT 분야 영어 용어를 익히고 싶은 개발자
  • 한국어 맞춤법과 어휘력을 키우고 싶은 분
  • 수학 기초 실력을 게임처럼 즐기며 키우고 싶은 분

기술 스택

VOCAB RUSH는 최신 웹 기술로 만들어졌습니다.

  • React 18 + Vite (빠른 빌드와 최적화된 성능)
  • PWA (Progressive Web App) - 오프라인 지원
  • Web Speech API - 브라우저 내장 음성 합성
  • 반응형 디자인 - 모바일/태블릿/데스크톱 모두 지원

학습 가이드

VOCAB RUSH를 더 효과적으로 활용하기 위한 학습 가이드를 확인하세요. AI 시대에 필요한 국·영·수 역량을 체계적으로 키울 수 있습니다.

  • AI 도구 활용 가이드 - ChatGPT, Claude 등 AI 도구를 200% 활용하는 방법
  • 프롬프트 엔지니어링 실전 가이드 - AI를 200% 활용하는 프롬프트 작성법
  • 영어 어휘 학습 가이드 - CEFR 레벨별 전략과 어휘 암기법
  • TOEIC 어휘 학습 전략 - 토익 고득점을 위한 핵심 어휘 학습법
  • 영어 접두사·접미사 완전 정복 - 어원으로 영단어를 빠르게 확장하는 방법
  • 수학 학습 가이드 - 프로그래밍·AI에 필요한 수학 기초
  • 코딩 테스트 수학 공식 - 개발자 취업을 위한 알고리즘 수학 핵심
  • 진법 변환 가이드 - 2진법, 8진법, 16진법의 원리와 실무
  • 한국어 학습 가이드 - IT 맞춤법과 비즈니스 한국어
  • 자주 틀리는 맞춤법 TOP 50 - 직장인·개발자가 가장 많이 틀리는 맞춤법
  • 효과적인 학습법 - 게이미피케이션과 간격 반복 학습의 과학

왜 VOCAB RUSH를 만들었나?

AI 시대가 도래하면서, ChatGPT와 Claude 같은 도구를 효과적으로 활용하려면 기초적인 국어, 영어, 수학 역량이 필수라는 것을 깨달았습니다. 영어로 정확한 프롬프트를 작성하고, 수학적 사고로 논리적 지시를 내리고, 정확한 한국어로 AI의 답변을 검증하는 능력이 곧 AI 시대의 경쟁력입니다.

VOCAB RUSH는 이러한 기초 역량을 게임처럼 재미있게 키울 수 있도록 만들어졌습니다. 출퇴근 시간 5분, 점심시간 10분의 짧은 학습으로도 꾸준히 실력을 쌓을 수 있습니다.

콘텐츠 제작 과정

VOCAB RUSH의 모든 학습 콘텐츠는 신뢰할 수 있는 출처를 기반으로 직접 제작되었습니다.

  • 영어 어휘: CEFR(유럽공통참조기준) 기반으로 5,500개 이상의 단어를 A1~C2 수준별로 분류. Oxford, Cambridge 사전을 참고하여 뜻과 예문을 검수했습니다.
  • 수학: 12개 카테고리의 무한 문제 생성 알고리즘을 직접 개발. 프로그래밍 수학, AI 수학 문제는 실제 코딩 테스트와 ML 교육과정을 참고했습니다.
  • 한국어: 국립국어원 표준국어대사전과 외래어 표기법을 기준으로 1,000개 이상의 문제를 제작. IT 용어는 한국정보통신기술협회(TTA) 표준을 참고했습니다.
