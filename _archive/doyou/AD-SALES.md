# STUDY RUSH 광고 영업 자료 (내부)

> 직접 판매(수주) 광고 = **Google AdSense와 별개 시스템** → 구글 광고 정책 무관.
> 매체: 학습 게임(웹 datapd.ai + 매장 키오스크). 광고 슬롯/엔진은 `public/suneung-quiz.html` + `public/ads/kiosk-ads.json`.
> 광고주용 공개 페이지: [`/advertise.html`](public/advertise.html). 관리 도구: [`/ad-admin.html`](public/ad-admin.html) · [`/ad-report.html`](public/ad-report.html).

---

## 1. 광고 상품 & 사양

| 상품 | 위치 | 노출 빈도 | 권장 규격 | 형식 |
|---|---|---|---|---|
| ① 하단 띠배너 | 화면 하단 고정(키오스크) | 게임 내내 상시 | 728×90 / 모바일 320×100 | 이미지 ≤150KB · HTML |
| ② 결과 카드 | 게임 결과 화면(웹·키오스크) | 한 판 종료마다 | 336×280 (4:3) | 이미지 ≤200KB · HTML |
| ③ 전면 광고 | 키오스크 유휴 attract | 60초 무동작 시 | 4:3 (960×720) | 이미지 · MP4 ≤15초/5MB · HTML |

- 슬롯에 여러 광고를 넣으면 **로테이션**(번갈아 노출). 게재기간(start/end)·노출초(seconds) 지원.
- 교체/등록은 `ad-admin.html`에서 → `kiosk-ads.json` 내보내 커밋(추후 원격 푸시).

## 2. 단가 모델 (※ 아래 숫자는 모두 **예시 초안** — 시장 테스트 후 확정)

| 방식 | 과금 기준 | 예시 기준가 | 적합 |
|---|---|---|---|
| 기간 정액형 | 매장당 · 슬롯당 · 월 | 띠배너 ₩10,000~30,000/매장·월 · 전면 ₩30,000~80,000/매장·월 | 지역 상권·정찰제 |
| 노출 과금(CPM) | 1,000회 노출당 | 결과/띠배너 ₩3,000~8,000 · 전면 ₩8,000~15,000 | 성과 검증·테스트 |
| 참여형 프리미엄 | 참여(노출+보상) 건당 | ₩50~200/참여 | 인지·체험 캠페인 |

- 견적 = (슬롯 × 매장 수 × 기간) 또는 (예상 노출 × CPM). 최소 집행 단위·기간 할인은 정책으로 별도 정함.
- **초기 전략:** 동네 상권(키오스크 설치 매장 인근) 소상공인에 띠배너 정액형으로 시작 → 노출 데이터 쌓이면 CPM/브랜드 영업 확대.

## 3. 판매 프로세스
1. 문의 접수(`/advertise.html` → 이메일) → 2. 소재·업종 검수(§5) → 3. 견적·계약 → 4. 소재 등록(`ad-admin.html`) → 5. 게재·노출 리포트(`ad-report.html` / 수집 시트) → 6. 정산.
